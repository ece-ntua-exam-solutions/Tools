# Υλικό ανάπτυξης

Ο ενεργός server ξεκινά αποκλειστικά από το `python studio_server.py` στον κύριο φάκελο `markdown-studio`.

- `tests/`: στοχευμένοι έλεγχοι, fixtures και αναφορές. Κάποιες παλαιότερες δοκιμές πλήρους LaTeX απαιτούν επιπλέον Pandoc/XeLaTeX και δεν αποτελούν μέρος της βασικής Python-only ροής.
- `ARCHITECTURE_v10.md`: ενότητες κώδικα και επιλογές υλοποίησης.
- `NEXT_VERSION.md`: καταγεγραμμένες επόμενες εργασίες.
- `examples/`: παράδειγμα Markdown.

Ιστορικά αντίγραφα εφαρμογών, παλιά launchers και δυαδικά παραδείγματα της αυτόνομης διανομής δεν περιλαμβάνονται στη δημοσίευση του repository. Η αναγνώριση εξισώσεων παραμένει πειραματική.
