# v10.0.1 — OCR περιοχές, γραμμές και έλεγχοι εξόδου

**Εγκατάσταση από το repository:** ο ενεργός φάκελος είναι `Tools/markdown-studio`. Οι παλιότερες αναφορές σε αποσυμπίεση ZIP αφορούν την αυτόνομη διανομή. Το OCR παραμένει πειραματικό.

Η v10.0.0 έστελνε ολόκληρη την εικόνα στο pix2tex ως μία έκφραση. Δεν υπήρχε εντοπισμός γραμμών ή προειδοποίηση για εκφυλισμένα αποτελέσματα με επαναλαμβανόμενα 1/I. Η προεπισκόπηση απέδιδε σωστά ακόμη και αυτό το λανθασμένο LaTeX.

## Χρήση

1. Άνοιξε **Εργαλεία LaTeX → Εικόνα → LaTeX** και ανέβασε/επικόλλησε εικόνα.
2. Το Studio εντοπίζει πιθανές γραμμές και δείχνει αριθμημένα πλαίσια. Αυτό το στάδιο απαιτεί Pillow/Python, όχι το OCR μοντέλο.
3. Έλεγξε ότι αριθμητής και παρονομαστής κάθε κλάσματος βρίσκονται **στο ίδιο πλαίσιο**. Επίλεξε ποιες γραμμές θέλεις.
4. Σύρε ορθογώνιο πάνω στην εικόνα για περιορισμό περιοχής. «Όλη η εικόνα» ακυρώνει τον περιορισμό.
5. Η «Μία εξίσωση / ενιαίο block» διατηρεί μαζί συστήματα ή matrices. Η αυτόματη λειτουργία και οι «Πολλές γραμμές λύσης» χωρίζουν τις γραμμές. Ο διαχωρισμός είναι γεωμετρικός και μπορεί να χρειαστεί διόρθωση από τις ρυθμίσεις.
6. Στις ρυθμίσεις, μεγαλύτερο κενό ενώνει περισσότερες ζώνες. Μικρότερο τις χωρίζει. Η μονάδα είναι pixel της εισαγόμενης εικόνας.
7. Πάτα αναγνώριση. Κάθε επιλεγμένη περιοχή στέλνεται χωριστά στο pix2tex και τα αποτελέσματα συνδυάζονται με `aligned`.
8. Αν εντοπιστούν ύποπτες επαναλήψεις ή ελλείψεις, εμφανίζεται προειδοποίηση. Η αντιγραφή/εισαγωγή ξεκλειδώνει μόνο αφού δηλώσεις ότι έλεγξες και διόρθωσες το ύποπτο αποτέλεσμα. Αλλαγή στον κώδικα ακυρώνει αυτή τη δήλωση.

Υπάρχει επιλογή αυτόματης κλίμακας του μοντέλου. Για ύποπτη έξοδο γίνεται προαιρετικά δεύτερη απόπειρα με την αντίθετη επιλογή κλίμακας. Οι διαθέσιμες απόπειρες εμφανίζονται ανά περιοχή, ώστε να διαλέξεις. Ο έλεγχος επαναλήψεων είναι ευρετικός· δεν μετρά βεβαιότητα, δεν αναγνωρίζει όλα τα λάθη και μπορεί να επισημάνει έγκυρα μαθηματικά με πολλές επαναλήψεις.

Το μοντέλο εξακολουθεί να απαιτεί `requirements-ocr.txt`. Η εικόνα παραμένει τοπική. Το πακέτο αναλύει πολλές γραμμές τύπων, όχι γενικές σελίδες εγγράφων, πίνακες ή αυθαίρετες διατάξεις/χειρόγραφα. Δεν εγγυάται μαθηματικά σωστή μεταγραφή.

## Τι ελέγχθηκε

Στην εικόνα που φαινόταν στο στιγμιότυπο ο εντοπισμός έδωσε **8 περιοχές**, διατηρώντας τα κλάσματα ενιαία. Αυτό ήταν έλεγχος διαχωρισμού, όχι πραγματική OCR αναγνώριση. Προστέθηκαν unit tests για κλάσματα, περιοχές, επαναλαμβανόμενα 1/μοναδιαία κλάσματα, δεύτερη απόπειρα κλίμακας, αποτυχία retry και συνδυασμό γραμμών. Οι κλήσεις μοντέλου σε αυτά τα tests είναι προσομοιωμένες.

Η χειροκίνητα σωστή μεταγραφή του συγκεκριμένου παραδείγματος βρίσκεται στο **examples/OCR_Example_Manual.md**. Δεν χρησιμοποιείται ως απάντηση του OCR.

## Αναβάθμιση

Κλείσε τον παλιό server, αποσυμπίεσε σε νέο φάκελο και τρέξε στο υπάρχον environment:

```bat
python -m pip install -r requirements.txt
python studio_server.py
```

Αν το pix2tex λειτουργούσε ήδη, δεν χρειάζεται νέα εγκατάσταση του μοντέλου. Άνοιξε το localhost και κάνε Ctrl+Shift+R. Οι παλιές λειτουργίες παραμένουν διαθέσιμες. Η πραγματική ποιότητα OCR με φορτωμένα βάρη παραμένει προς δοκιμή.
