# Οδηγός v10.0.1

**Εγκατάσταση από το repository:** ο ενεργός φάκελος είναι `Tools/markdown-studio`. Οι παλιότερες αναφορές σε αποσυμπίεση ZIP αφορούν την αυτόνομη διανομή. Το OCR παραμένει πειραματικό.

Για το ενημερωμένο OCR ακολούθησε το **UPDATE_v10_0_1.md**.

## Το καθημερινό περιβάλλον

Η «Συγγραφή» έχει την πηγή αριστερά και την προεπισκόπηση δεξιά. Οι άλλες λειτουργίες έχουν δική τους προβολή. Το «×» επάνω δεξιά επιστρέφει στον editor. Σε ξεχωριστό παράθυρο εργαλείου κλείνει το παράθυρο, όταν το επιτρέπει ο browser. Το «?» εξηγεί τη λειτουργία και οδηγεί σε σχόλιο για αυτήν. Το «↗» αντιγράφει τον άμεσο σύνδεσμο.

- **Ctrl+K:** αναζήτηση λειτουργίας.
- **Ctrl+F** στον editor: εύρεση μέσα στην πηγή, με προηγούμενο/επόμενο.
- **Ctrl+S:** λήψη του Markdown από τον editor.
- **↑ / ↓ / Enter:** επιλογή πρότασης αναζήτησης.
- **Escape:** κλείσιμο προτάσεων ή επιστροφή από την τρέχουσα προβολή. Ανοιχτό dialog κλείνει πρώτα με Escape.

Η πρόχειρη πηγή αποθηκεύεται στον συγκεκριμένο browser. Αυτό δεν αντικαθιστά την Αποθήκευση .md ή το GitHub. Τα στοιχεία εξέτασης, προφίλ ενημέρωσης και θέμα κρατιούνται στον ίδιο browser. Δεν υπάρχει ακόμη σύστημα λογαριασμών/συγχρονισμού των ρυθμίσεων μεταξύ υπολογιστών.

## Αναζήτηση μαθημάτων και κατηγοριών

Στα Στοιχεία εξέτασης διάλεξε εξάμηνο και έτος εξέτασης. Με «Ανανέωση από GitHub» φορτώνονται οι ακριβείς διαδρομές. Οι προτάσεις μαθήματος ακολουθούν τα δύο φίλτρα και αλλάζουν αμέσως όταν αλλάξει οποιοδήποτε από αυτά. Άκυρη παλιά επιλογή καθαρίζεται. Στις ενημερώσεις, αν έχεις περιορίσει έτος/εξάμηνο, περιορίζονται ανάλογα και οι προτάσεις μαθημάτων.

Η αναζήτηση αγνοεί τόνους, πεζά/κεφαλαία, τελικό σίγμα και διαχωριστικά, αναγνωρίζει προθέματα και ανέχεται κοντινές ορθογραφικές γραφές. Υποστηρίζονται επίσης ορισμένες φωνητικές λατινικές γραφές. Δεν εγγυάται κάθε πιθανό Greeklish ή νοηματική αντιστοιχία. Οι προτάσεις βασίζονται στον πραγματικό κατάλογο. Κάνε κλικ στην πρόταση για διόρθωση· η εφαρμογή δεν αλλάζει αυτόματα το canonical όνομα φακέλου.

## Ενημερώσεις και email

1. Πάτα Ανάκτηση από GitHub. Χρησιμοποιείται το κοινό `ece-ntua-exam-solutions/Problems-Solutions`.
2. Αναζήτησε στα φορτωμένα PR με λέξεις από τίτλο, περιγραφή, labels, συντάκτη ή αρχεία. Υπάρχουν προτάσεις για τίτλους και μαθήματα.
3. Στα «Φίλτρα και προφίλ» μπορείς να περιορίσεις διαδρομή κατηγορίας, μάθημα, έτος, εξάμηνο, κατάσταση, ημερομηνία ενημέρωσης, συντάκτη, labels και drafts. Με αλλαγή φίλτρων χρειάζεται νέα ανάκτηση. Η απλή αναζήτηση στο report είναι τοπική και δεν κάνει νέο API request.
4. Επίλεξε αν η περιγραφή και η λίστα αρχείων θα μπουν στο report/email.
5. Αποθήκευσε ονομασμένο προφίλ για επόμενη φορά. Η αναζήτηση προφίλ το επαναφέρει.
6. Κατέβασε HTML ή δώσε παραλήπτες/θέμα στην ενότητα Email και πάτα Email. Επιβεβαίωσε πριν την αποστολή. Στέλνεται το **εμφανιζόμενο φιλτραρισμένο report**.

Τα φίλτρα συνδυάζονται με AND, τα labels με OR. Κατηγορία σημαίνει πραγματικό πρόθεμα διαδρομής ή label. «Κλειστά» περιλαμβάνει merged· υπάρχει ξεχωριστή επιλογή μόνο merged. Η ημερομηνία αφορά τελευταία ενημέρωση PR. Τα reports είναι στιγμιότυπα, όχι σύστημα unread. Δεν λειτουργεί scheduler ούτε υπηρεσία όταν η εφαρμογή είναι κλειστή.

Η ανάκτηση χρησιμοποιεί pagination και μικρή προσωρινή μνήμη έως 90 δευτερόλεπτα για επαναλαμβανόμενα αιτήματα. Πολλά PR απαιτούν περισσότερα API requests και χρόνο. Για public δεδομένα λειτουργεί και χωρίς gh, με χαμηλότερα όρια GitHub. Η σύνδεση gh βοηθά στα όρια. Το GitHub περιορίζει τη λίστα αλλαγμένων αρχείων σε 3000 ανά PR· εμφανίζεται σχετική ένδειξη όταν φτάνεται το όριο.

### Ρύθμιση SMTP

Στο ίδιο Anaconda Prompt όπου θα ξεκινήσει ο server:

```bat
set "STUDIO_SMTP_HOST=smtp.example.org"
set "STUDIO_SMTP_PORT=587"
set "STUDIO_SMTP_SECURITY=starttls"
set "STUDIO_SMTP_FROM=your-address@example.org"
set "STUDIO_SMTP_USER=your-address@example.org"
set /p "STUDIO_SMTP_PASSWORD=SMTP app password: "
python studio_server.py
```

Για implicit TLS: `STUDIO_SMTP_SECURITY=ssl` και θύρα 465. Οι ρυθμίσεις εξαρτώνται από τον πάροχο· όπου απαιτείται χρησιμοποίησε app password. Οι κωδικοί δεν αποθηκεύονται στον browser ή στα σχόλια. Το παράδειγμα `set /p` εμφανίζει την πληκτρολόγηση στο terminal· χρησιμοποίησε ιδιωτικό παράθυρο. Αποδοχή από SMTP δεν αποτελεί εγγύηση παράδοσης στο inbox. Δεν έγινε πραγματική αποστολή κατά την ανάπτυξη.

## Εξισώσεις και πίνακες

Οι εξισώσεις δέχονται έτοιμα blocks ή δικό σου LaTeX. Εμφανίζονται μέσω MathJax. Αντιγράφονται σκέτες ή με delimiters για Markdown. Το σύνολο των blocks καλύπτει κλάσματα, ολοκληρώματα, παράγωγους, συστήματα, matrices και συνηθισμένους τύπους ηλεκτρολογίας. Δεν κάνει συμβολική επίλυση ή έλεγχο της λύσης.

Ο δημιουργός πίνακα δέχεται 1–20 γραμμές και 1–12 στήλες, επικόλληση TSV από Excel, επιλογή κεφαλίδας και στοίχισης. Εξάγει Markdown, LaTeX tabular, array ή bmatrix. Για Markdown πίνακα χωρίς κεφαλίδα δημιουργείται κενή γραμμή κεφαλίδας, όπως απαιτεί η σύνταξη Markdown. Στο tabular τα ειδικά σύμβολα κειμένου γίνονται escape· μαθηματικά `$...$` διατηρούνται. Σε array/matrix τα κελιά θεωρούνται LaTeX μαθηματικά.

Η HTML/MathJax προεπισκόπηση δεν ισοδυναμεί με LaTeX compiler. Το βασικό Python PDF χρησιμοποιεί matplotlib mathtext και δεν υποστηρίζει όλες τις εντολές (π.χ. σύνθετα `aligned`/TikZ). Ελέγχετε την τελική εξαγωγή.

## Εικόνα εξίσωσης → LaTeX

Προαιρετική εγκατάσταση στο κατάλληλο Conda environment:

```bat
python -m pip install -r requirements-ocr.txt
python studio_server.py
```

Χρησιμοποιείται `pix2tex==0.1.4` και PyTorch. Δεν εγκαθίσταται με τα βασικά requirements. Για συμβατότητα προτιμάται καθαρό environment Python 3.10/3.11. Απαιτείται πρόσβαση στο διαδίκτυο για εγκατάσταση/πρώτη λήψη βαρών. Επίσημη τεκμηρίωση: https://github.com/lukas-blecher/LaTeX-OCR

Επίλεξε PNG/JPEG/WebP ή σύρε/επικόλλησε εικόνα. Δώσε μία καθαρή εξίσωση ή διαδοχικές γραμμές λύσης και έλεγξε τα πλαίσια (δες UPDATE_v10_0_1.md), όχι ολόκληρη σελίδα, έως 8 MB / 16 megapixel. Επίλεξε φόρτωση μοντέλου και πάτα Αναγνώριση. Η εικόνα επεξεργάζεται τοπικά. Το μοντέλο φορτώνεται μόνο τότε και επαναχρησιμοποιείται στις επόμενες αναγνωρίσεις. Ο Έλεγχος εγκατάστασης διακρίνει το εγκατεστημένο πακέτο από ήδη φορτωμένο μοντέλο.

Το αποτέλεσμα είναι επεξεργάσιμο και έχει προεπισκόπηση, αντιγραφή LaTeX/Markdown και εισαγωγή στον editor. Μπορεί να κάνει λάθη σε σύμβολα, δείκτες ή χειρόγραφα. Δεν αποτελεί πλήρες σύστημα μεταγραφής χειρόγραφων/σχημάτων· εκείνο το project παραμένει ξεχωριστό. Στην ανάπτυξη ελέγχθηκαν η διαδρομή εικόνας, τα όρια, τα σφάλματα και προσομοιωμένη αναγνώριση. Δεν εκτελέστηκε πραγματική αναγνώριση με βάρη pix2tex.

## Σχόλια για το Discord

Από οποιοδήποτε «?» πάτα «Σχόλιο για αυτή τη λειτουργία». Επίλεξε τύπο, γράψε σχόλιο/βήματα και προαιρετικά πρόσθεσε αρχεία. Μπορείς να κρατήσεις σχόλια για πολλές λειτουργίες. Αποθηκεύονται στον browser. Τα συνημμένα παραμένουν στη μνήμη της σελίδας και πρέπει να εξαχθούν πριν κλείσει ή ανανεωθεί.

Το «Λήψη φακέλου ZIP για Discord» δημιουργεί:

```text
Markdown_Studio_Feedback/
  README.md
  comments.json
  comments/
    reports.md
    equations.md
  attachments/
    reports/
```

Το ZIP λειτουργεί και σε HTML-only, χωρίς server. Περιλαμβάνει σχόλια και μόνο τα συνημμένα που επέλεξες, όχι την πηγή του εγγράφου ή στοιχεία SMTP. Επισύναψέ το χειροκίνητα στο Discord. Δεν χρησιμοποιείται webhook ούτε token του Discord.
